# Edge Controller Hardware Specifications Datasheet

- **Compute**: Raspberry Pi CM4 (Quad-core Cortex-A72 @ 1.5GHz, 4GB LPDDR4, 32GB eMMC).
- **Display**: 5-inch 720x1280 IPS Capacitive Touchscreen (Seeed reTerminal).
- **I/O Expansion**: I2C Bus 1, 1-Wire sysfs, Dual L298N H-Bridge Peristaltic Drivers.
