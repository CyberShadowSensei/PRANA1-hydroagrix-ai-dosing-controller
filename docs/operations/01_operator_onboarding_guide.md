# Prana 1 Operator Onboarding Guide

## Introduction
Prana 1 is an enterprise-grade automated dosing controller. This guide provides step-by-step instructions for initial reservoir setup, sensor calibration, solution replenishment, and autonomous crop cycle launching.

## First-Time Reservoir Setup
1. Fill main reservoir with reverse osmosis (RO) or clean tap water.
2. Allow water temperature to stabilize between 18°C and 24°C.
3. Verify that the EC and pH probes are fully submerged in active circulation.
